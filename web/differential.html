Method. Effective multipliers are recomputed in your browser from the raw scaledUiAmountConfig state published in the feed, using the same rule the program uses — now >= newMultiplierEffectiveTimestamp ? newMultiplier : multiplier. Sizes and prices cancel out of the error factor, so the multiplier gap is the whole story at any position size.
